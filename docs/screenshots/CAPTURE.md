# Screenshot capture list — PrintCAD Lite

Screenshots for the README are taken from **real runs on SEAN's
Windows machine**. Do not use placeholder, stock or generated
images. Wire each capture into `README.md` as soon as it is
supplied.

## Capture settings (all shots)

- Display scaling: **100%**
- Theme: dark (the standard black/red PrintCAD Lite theme)
- Window size: **1600×1000 or larger**
- Use the same example scene for shots 1–3 so the views match
- Save as PNG, named exactly as listed below, in this folder

## Captures

1. **Main window — starter scene in the 3D view**
   - File: `01-main-starter-scene.png`
   - The starter scene (box + cylinder) in the 3D viewport, with the
     object list on the left and the stats bar visible at the bottom.

2. **Inspector — editing an object**
   - File: `02-inspector.png`
   - A cylinder selected, the inspector on the right showing its
     position, rotation, radius, height and segments fields.

3. **A small assembly — several shapes arranged**
   - File: `03-assembly.png`
   - At least four objects of different shapes (one flagged as a
     hole, labelled "(hole)" in the object list) arranged into a
     simple part, orbited to a readable angle.

4. **Export result**
   - File: `04-export-status.png`
   - The main window just after an STL export, with the status line
     showing the exported triangle count and file path.
